# 🧸 Реферальный бот «Мишка за друзей»

Пользователь запускает бота, проходит обязательную подписку, приглашает N друзей и получает
подарок Telegram 🧸. Бот сам дарит его за звёзды со своего баланса или создаёт заявку для админа.

Стек: **aiogram 3.31**, SQLite (aiosqlite), Python 3.11+.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN и свой ID в ADMIN_IDS
python -m bot
```

### Docker

```bash
cp .env.example .env        # впишите BOT_TOKEN и ADMIN_IDS
docker compose up -d --build
docker compose logs -f      # логи
```

База SQLite лежит в именованном томе `bot-data` и переживает пересборку контейнера.
Обновление: `git pull && docker compose up -d --build`.
Бэкап базы: `docker compose cp bot:/app/data/bot.db ./bot.db`.

Бота нужно добавить **администратором** во все каналы из обязательной подписки, иначе он не сможет проверить подписку.

## Пользователь

- `/start` → экран подписки: кнопки только на те каналы, где он ещё не состоит, и кнопка «✅ Я подписался».
  Если подписался не везде, всплывает окно со списком оставшихся каналов, а экран обновляется.
- **Реферал засчитывается только после прохождения подписки.** Пригласившему приходит уведомление с прогресс-баром.
- Меню открывается одним сообщением, которое редактируется, так что чат не засоряется. Над каждым экраном —
  **баннер** (`bot/assets/banner.webp`, можно заменить в админке). Главное меню: зелёная «Получить подарки!»,
  синяя «💎 НФТ подарки» (если раздел включён), «Заработать звёзды», «Ежедневный кейс», «Купить подарки», «👤 Профиль / Баланс» и синяя ссылка
  «Мой канал с раздачами» (если задана в админке). На кнопках — премиум-эмодзи; без Telegram Premium у владельца
  бота они автоматически заменяются обычными.
- **Получить подарки!** — награда за друзей: прогресс `▰▰▰▱▱ 60%`, «🔗 Пригласить» (кнопки «Поделиться» и
  «Скопировать ссылку»), «👥 Мои друзья», «🏆 Топ» и «❓ Как это работает». Когда цель достигнута, появляется
  зелёная кнопка «🧸 Забрать мишку». Двойное нажатие не выдаст второй подарок.
- **Заработать звёзды** — задания из админки: подписаться на канал, отдать буст или перейти по ссылке. Подписка и
  буст проверяются автоматически (бот должен быть админом канала), ссылка — без проверки, но не раньше чем через
  5 секунд. Награда (можно дробную, например 0.25 ⭐) зачисляется на **баланс в боте**, выполненное задание пропадает.
- **Ежедневный кейс** — магазин кейсов: звёзды с баланса тратятся на кейсы, приз — подарок Telegram (отправляется
  со звёзд бота) или звёзды обратно на баланс. Ежедневный кейс бесплатный, раз в сутки.
- **Профиль / Баланс** — баланс, сколько выполнено заданий и открыто кейсов.
- Если пользователь отпишется, то при следующем действии снова увидит экран подписки.
- Для приватных каналов с заявками на вступление поданная заявка засчитывается как подписка.

| ⭐ Баланс | текущий баланс, на сколько подарков хватит, сколько нужно на заявки в очереди; пополнение готовой или своей суммой |
| 📊 Статистика | новые пользователи за день, 7 и 30 дней; активные; конверсия рефералов; награды; график за 7 дней; **выгрузка CSV** |
| 📎 Рекламные ссылки | ссылка `t.me/бот?start=ad_код` на каждую площадку: своё название, свой или случайный код. Статистика: переходы (всего, уникальные, сегодня), новые и вернувшиеся пользователи, прохождение подписки, сколько друзей они привели, достигли цели и получили наград, активность за 24 ч и 7 дней, блокировки бота; при указанной стоимости — цена перехода, нового пользователя и подписчика; график по дням за 7/14/30 дней; CSV пользователей по ссылке; архив |

Вкл/выкл, количество, интервал, варианты текстов (по умолчанию 5), текст кнопки, картинка, превью, конверсия по номеру напоминания |

| 🎟 Чеки | подарочные чеки через inline, свой баннер для каждого подарка и общий баннер, список, карточка (активации, новые пользователи, выданные подарки), список активировавших, выключение и удаление. Сообщение чека в чате никогда не меняется — кнопка всегда ведёт в бота |
| 📢 Каналы | добавить канал **нативной кнопкой выбора чата**, пересылкой поста, через @username или ID; включить/выключить, порядок, своя или новая инвайт-ссылка, удаление с подтверждением |

Одиночно: канал из списка подписки, недавних, кнопкой выбора, по @username/ссылке/ID или пересланному посту → подарок → количество (1–20) и подпись → отправка с итогом и ошибкой, если звёзд не хватило |

| 💰 Задания | задания «Заработать звёзды»: 📢 подписка и 🚀 буст канала (выбор кнопкой, @username, ID или пересланный пост; проверка автоматически) и 🔗 ссылка; награда в звёздах (дробная), текст и цвет кнопки, ссылка, лимит выполнений, порядок, вкл/выкл; сколько выполнено и начислено; предупреждение, если бот не админ канала |
| 📦 Кейсы | кейсы за звёзды с баланса: название, цена (0 — бесплатный), эмодзи или премиум-эмодзи на кнопке, цвет, «раз в сутки», порядок; призы — подарки Telegram или звёзды на баланс с шансами; средний приз и RTP; открытия, потрачено, выдано. При первом запуске создаётся «Ежедневный кейс» (0.1–1 ⭐ на баланс) |
| 🏠 Главное меню | баннер вкл/выкл, свой баннер (фото) или по умолчанию, ссылка кнопки «Мой канал с раздачами» |

Любая кнопка или команда отменяет незавершённый ввод, поэтому админ не «застрянет» в режиме ввода.

## Мини-апп «Рулетка подарков»

Игрок платит звёзды (по умолчанию кейсы «Все» — 25 ⭐ и «Романтика» — 42 ⭐), крутит рулетку и выигрывает подарок Telegram.

- Интерфейс в стиле Telegram: цвета темы пользователя (светлая/тёмная), хаптика, оригинальные анимации подарков (Lottie), вкладки «Играть» и «Профиль», демо-режим без оплаты.
- Приз разыгрывается **на сервере в момент оплаты** (криптостойкий ГСЧ), рулетка лишь докручивается до результата — подменить выигрыш из браузера нельзя. Каждый запрос к API проверяется по подписи Telegram `initData`.
- Подарок отправляется сразу. Если звёзд у бота не хватило — выигрыш попадает в «🎁 Заявки», где его можно отправить позже или вернуть игроку звёзды.
- Кейсы, призы и шансы настраиваются в `/admin` → «🎰 Рулетка». Шанс = вес приза / сумма весов, поэтому сумма не обязана быть ровно 100.

**Запуск через Cloudflare Tunnel (проще всего, порты открывать не нужно):**
1. Домен добавлен в Cloudflare. Zero Trust → Networks → Tunnels → Create a tunnel → Cloudflared → скопируйте токен.
2. В туннеле Public Hostname: поддомен (например `gifts`), домен, Service `HTTP` → `bot:8080`.
3. В `.env`: `TUNNEL_TOKEN=<токен>` и `WEBAPP_URL=https://gifts.example.com`.
4. `docker compose --profile tunnel up -d --build`.

**Или через свой сервер с Caddy.** Telegram открывает мини-апп только по HTTPS:
1. Направьте домен (например `gifts.example.com`) на сервер, откройте порты 80 и 443.
2. В `.env`: `DOMAIN=gifts.example.com` и `WEBAPP_URL=https://gifts.example.com`.
3. `docker compose --profile https up -d --build` — Caddy сам выпустит сертификат и проксирует на бота.

**С оранжевым облаком Cloudflare (IP сервера скрыт):**
1. A-запись `gifts` → IP сервера, Proxy status — **Proxied**.
2. SSL/TLS → Overview → режим **Full (strict)**.
3. SSL/TLS → Origin Server → **Create Certificate** (15 лет). Сертификат сохраните в `certs/origin.pem`, приватный ключ — в `certs/origin.key` (ключ показывается один раз).
4. В `.env`: `CADDYFILE=./Caddyfile.cloudflare`, плюс `DOMAIN` и `WEBAPP_URL` как выше.
5. `docker compose --profile https up -d --build`.

Свой nginx/Caddy на хосте? Проксируйте на `127.0.0.1:8080` и укажите `WEBAPP_URL`. После запуска у бота появится кнопка меню «🎰 Рулетка» и кнопка в главном меню.

Посмотреть интерфейс локально без Telegram: `python -m tests.webapp_preview` и открыть напечатанную ссылку.

## Магазин подарков

В меню — кнопка «Купить подарки»: кнопки в стиле «🧸 мишка - 15 ⭐» по две в ряд, цвет по ценовой категории (50 ⭐ — синие, 100 ⭐ — зелёные). Пользователь оплачивает счёт в Stars по цене, которую задал админ, и бот сразу дарит подарок со своего баланса (стоимость подарка в Telegram списывается с баланса бота).

- Два варианта покупки: **с нашим комментарием** — по цене магазина (текст в «💬 Наш комментарий», `{bot}` — юзернейм бота), или **со своим комментарием** — по себестоимости, но текст только из готовых вариантов («✍️ Свои варианты», до 20 шт., до 128 символов). Нет вариантов — второй кнопки нет. Покупатель видит текст подписи до оплаты.
- По умолчанию в магазине обычные подарки (мишка, сердце, подарок, роза, торт, букет, ракета, бутылка, алмаз, кольцо, кубок) по цене Telegram; лимитированные включаются вручную.
- Если звёзд у бота не хватает, оплата отклоняется ещё до списания, а админам приходит уведомление (не чаще раза в час).
- Не получилось отправить подарок после оплаты — звёзды автоматически возвращаются покупателю, админы получают уведомление.
- Цену, изменённую после выставления счёта, оплатить по старой цене нельзя.

## НФТ подарки и юзербот

В меню бота появляется «💎 НФТ подарки» (когда есть хотя бы один видимый подарок). Пользователь выбирает подарок и видит инструкцию: **1️⃣ написать админу** — кнопка «✍️ Написать админу», **2️⃣ ждать подарок**. У каждого подарка своя **ссылка на чат** с юзерботом (Telegram Business → «Ссылки на чат»): она открывает чат с готовым сообщением, по умолчанию «Привет, оплата за {gift}», где `{gift}` — название подарка. Ссылки создаются, переименовываются и удаляются вместе с подарками; текст меняется в «💬 Текст сообщения», в карточке подарка видно число переходов. Нужен Telegram Premium на аккаунте юзербота. Пока ссылки нет, кнопка ведёт на «запасную ссылку» (для `t.me/username` — с тем же готовым текстом).

**Юзербот** — обычный аккаунт Telegram, которому пишут покупатели. На каждое сообщение (и на каждое повторное) он сразу отвечает текстом из админки, по умолчанию «🎁 Админ скоро отправит вам подарок!». Контактам и ботам не отвечает; можно включить режим «только платные сообщения». Платные сообщения включаются в самом аккаунте: Настройки → Конфиденциальность → Сообщения.

Подключение:
1. На https://my.telegram.org → API development tools получите `api_id` и `api_hash` и впишите в `.env`: `USERBOT_API_ID`, `USERBOT_API_HASH`.
2. Перезапустите бота и войдите в аккаунт (спросит телефон, код и пароль 2FA):
   ```bash
   docker compose run --rm bot python -m bot.userbot_login
   ```
3. В `/admin` → «💎 НФТ подарки» → «🤖 Юзербот» → «🔄 Переподключить».

Сессия хранится в `data/userbot.session` (в volume с базой) — это полный доступ к аккаунту, не передавайте её никому.

## Чеки на подарки

1. В @BotFather включите inline-режим: `/setinline`. Желательно также `/setinlinefeedback` → Enabled — тогда отправленные чеки сразу появляются в админке.
2. Загрузите баннеры в `/admin` → «🎟 Чеки» (JPG или PNG, фото или файлом, до 10 МБ, лучше горизонтальные, например 1280×720):
   - **«🎨 Баннеры подарков»** — свой баннер для каждого подарка, показывается в чеке как есть;
   - **«🖼 Общий баннер»** — для подарков без своего: бот сам добавит на него значок подарка и цену.
   Подарок без своего баннера при отсутствии общего отправляется текстовым чеком.
3. В любом чате напишите `@ваш_бот 10` (или `@ваш_бот 10 С праздником!` — со своей подписью). Бот покажет **все доступные подарки** со своими баннерами. Нажмите нужный — чек уйдёт в чат.

- Один пользователь активирует чек один раз, лимит активаций соблюдается даже при одновременных нажатиях.
- Перед каждой активацией бот заново проверяет подписку на все каналы. Если человек не подписан, он увидит экран подписки, а после подписки получит подарок.
- Подарок выдаётся по режиму из настроек: автоматически за звёзды или заявкой админам.
- **Чек с паролем:** `@ваш_бот 10 пароль:весна С праздником!` (или `pass:весна`, `🔑весна`). В тексте чека пароля нет — только пометка 🔐. После перехода и подписки бот просит пароль сообщением; регистр не важен; после 5 неверных попыток — пауза 10 минут. Пароль виден в карточке чека в админке.
- Повторно отправить чек: `@ваш_бот #код` или кнопка «📤 Отправить ещё раз» в карточке чека.
- Обычный пользователь через `@ваш_бот` может отправить другу свою реферальную ссылку.

## Награда

- **Авто** (по умолчанию): `sendGift` за звёзды бота. Если звёзд не хватило, заявка уходит в очередь, а админы получают уведомление с кнопками.
- **Вручную**: каждая заявка приходит админам, выдают сами.
- Баланс пополняется кнопкой **«⭐ Баланс: N — пополнить»** прямо на дашборде `/admin` (она же есть в заявках, чеках и выборе подарка; красная, если звёзд не хватает на подарок). Готовые суммы или своя от 1 до 10 000 ⭐ — бот присылает счёт в Stars, после оплаты звёзды сразу поступают на баланс.
- «Повторные награды» включают выдачу мишки за каждые N друзей, а не один раз.
