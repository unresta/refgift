# 🧸 Реферальный бот «Мишка за друзей»

Пользователь запускает бота, проходит обязательную подписку, приглашает N друзей и получает
подарок Telegram 🧸. Бот сам дарит его за звёзды со своего баланса или создаёт заявку для админа.

Стек: **aiogram 3.31**, SQLite (aiosqlite), Python 3.11+.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN и свой ID в ADMIN_IDS
python -m bot
```

### Docker

```bash
cp .env.example .env        # впишите BOT_TOKEN и ADMIN_IDS
docker compose up -d --build
docker compose logs -f      # логи
```

База SQLite лежит в именованном томе `bot-data` и переживает пересборку контейнера.
Обновление: `git pull && docker compose up -d --build`.
Бэкап базы: `docker compose cp bot:/app/data/bot.db ./bot.db`.

Бота нужно добавить **администратором** во все каналы из обязательной подписки, иначе он не сможет проверить подписку.

## Пользователь

- `/start` → экран подписки: кнопки только на те каналы, где он ещё не состоит, и кнопка «✅ Я подписался».
  Если подписался не везде, всплывает окно со списком оставшихся каналов, а экран обновляется.
- **Реферал засчитывается только после прохождения подписки.** Пригласившему приходит уведомление с прогресс-баром.
- Меню открывается одним сообщением, которое редактируется, так что чат не засоряется:
  прогресс `▰▰▰▱▱ 60%`, «🔗 Пригласить» (кнопки «Поделиться» и «Скопировать ссылку»),
  «👥 Мои друзья» (кто засчитан, а кто ещё не подписался), «🏆 Топ» с местом пользователя и «❓ Как это работает».
- Когда цель достигнута, в меню появляется зелёная кнопка «🧸 Забрать мишку». Двойное нажатие не выдаст второй подарок.
- Если пользователь отпишется, то при следующем действии снова увидит экран подписки.
- Для приватных каналов с заявками на вступление поданная заявка засчитывается как подписка.

## Админ-панель — `/admin`

| Раздел | Возможности |
|---|---|
| 🏠 Дашборд | ключевые цифры, баланс звёзд и на сколько подарков его хватит, предупреждения (бот не админ в канале, мало звёзд, включены техработы) |
| 📊 Статистика | новые пользователи за день, 7 и 30 дней; активные; конверсия рефералов; награды; график за 7 дней; **выгрузка CSV** |
| 📢 Каналы | добавить канал **нативной кнопкой выбора чата**, пересылкой поста, через @username или ID; включить/выключить, порядок, своя или новая инвайт-ссылка, удаление с подтверждением |
| 🎁 Заявки | вкладки «ожидают», «выданы», «отклонены»; отправить подарок, отметить выданным вручную, отклонить; **«Отправить все»** после пополнения звёзд |
| 👥 Пользователи | поиск по ID, @username или пересланному сообщению; карточка с прогрессом; ±1 друг, бан, сброс наград, отправить мишку, написать от имени бота, список рефералов; топ, новые, забаненные |
| 📨 Рассылка | 3 шага: сообщение (любой тип, форматирование сохраняется) → кнопки-ссылки → аудитория (все / прошли подписку / не прошли / достигли цели / активные) → превью → живой прогресс с остановкой |
| ⚙️ Настройки | цель (кнопки ➖/➕, готовые значения или ввод числа), авто- или ручная выдача, **выбор подарка из доступных**, подпись к подарку, повторные награды, уведомления, кэш проверки, техработы, **пополнение баланса звёзд счётом XTR**, тестовый подарок себе |
| 📝 Тексты | все тексты бота с превью; редактируются обычным форматированием Telegram, есть откат к тексту по умолчанию |
| 👮 Админы | главные админы (из `.env`) добавляют и удаляют дополнительных |

Любая кнопка или команда отменяет незавершённый ввод, поэтому админ не «застрянет» в режиме ввода.

## Награда

- **Авто** (по умолчанию): `sendGift` за звёзды бота. Если звёзд не хватило, заявка уходит в очередь, а админы получают уведомление с кнопками.
- **Вручную**: каждая заявка приходит админам, выдают сами.
- Баланс пополняется в разделе «Настройки → Выбрать подарок → ⭐ Пополнить баланс»: бот присылает счёт в Stars, после оплаты звёзды поступают на его баланс.
- «Повторные награды» включают выдачу мишки за каждые N друзей, а не один раз.

## Структура

```
bot/
  __main__.py          сборка и запуск
  config.py            .env
  database.py          схема и запросы SQLite
  settings.py          настройки и тексты по умолчанию
  views.py             экраны пользователя
  middlewares.py       регистрация, бан/техработы, антифлуд, проверка подписки
  services/            подписка, награды, рассылка, админы
  handlers/user.py     пользовательская часть + join requests / платежи
  handlers/admin/      разделы админ-панели
tests/smoke_test.py    офлайн-прогон всех сценариев на фейковом Telegram API
```

Тесты: `python -m tests.smoke_test`
